# 使徒行傳

一座城一個地點，一條線一段旅程。在真實海岸線的地中海地圖上，看福音如何從耶路撒冷一站一站傳到羅馬。

靈感來自沈伯洋競選團隊的「HEART 政策島」。這裡只借用它的做法（程序化 3D 場景、一份資料驅動整個場景、協作線、導覽），程式與美術都是重新寫的。

## 執行

純靜態網頁，不需要建置。因為用了 ES module，要透過本機伺服器開啟（直接雙擊 `index.html` 不行）：

```bash
python -m http.server 5185 --directory acts-island
```

再開 http://localhost:5185 。Three.js 0.160 從 jsDelivr CDN 載入。

## 畫面

- **地圖**：Natural Earth 1:50m 的真實海岸線，擠出成薄板，加上山脈、樹、經緯線，以及和合本譯名的地區與海名（馬其頓、亞該亞、亞細亞、大海…）。
- **城市**：24 個地點依實際經緯度擺放，平台顏色是 1:8 的四個圈（耶路撒冷／猶太全地／撒馬利亞／直到地極）。城上每棟小建築是一件事，建築樣式依事件類型（聖殿、會堂、監牢、船…）。
- **聖經人物**：15 位 Q 版人物（彼得、保羅、巴拿巴、腓利、司提反、呂底亞、提摩太…）帶著名牌，照使徒行傳的順序在城市之間走動，走在地上、過海時坐船。選「全部」時把一生走一遍；選一個時期就只走那段時間的地點。保羅在 13:9 以前的名牌顯示「掃羅（保羅）」。點名牌會打開人物頁，鏡頭跟著他走。
- **相遇與對話**：19 段相遇（例如大馬色路上、河邊的呂底亞、半夜的詩歌）。有對話的城市上方有 💬 泡泡；點泡泡、城市頁或人物頁的「相遇」，相關人物會聚到同一座城面對面，對話框一句句播放（台詞與旁白取自和合本），最後留一個「想一想」的問題。跟著人物走、或自己的角色走行程時，到了有對話的城會跳出提示。
- **我的角色**：自訂外觀，選一段旅程走一遍，沿途記錄旅程日誌，可以拍照下載。
- **時間**：清晨、白天、黃昏、夜晚自動流動，可以暫停；可關掉名牌與旅程線。
- **旅程線**：9 段旅程。點一段旅程，會有一個人沿路線走一遍，每到一座城停一下。
- **時間軸**：依章節分成 7 個時期，選一個時期只亮出那段時間的地點與旅程。
- **導覽**：「跟著 1:8 走一遍」，9 站。
- **搜尋**：地點、事件、旅程，也可以直接搜經文出處（如 `16:9`）。

## 檔案

```
index.html      頁面骨架
css/style.css   樣式（深／淺色、手機版底部面板）
js/data.js      全部內容：地點、事件、旅程、時期、導覽
js/land.js      陸地輪廓資料（由 tools/make-land.mjs 產生）
js/world.js     經緯度投影、陸地判斷、城市上的建築擺放
js/scene.js     Three.js 場景：海、陸地、山、城市、建築、小人、旅程線
tools/make-land.mjs  把 world-atlas 的 land-50m.json 裁切、簡化成 js/land.js
js/app.js       面板、搜尋、時間軸、導覽
```

## 改內容

只要改 `js/data.js`：

- 新增地點：在 `places` 加一筆，填經緯度（`lon`、`lat`）就會擺到地圖上的實際位置。
- 新增事件：在地點的 `events` 加 `{ t, r, kind }`，`kind` 可用 `temple / synagogue / house / prison / market / ship / road / tree`。
- 新增旅程：在 `journeys` 加一筆，`route` 是依序經過的地點 id，`stops` 是每一段的經文（數量比 `route` 少 1），`walkers` 是走這段路的人物 id（選了這段旅程時，地圖上同一個人不會出現兩次）。
- 新增人物：在 `characters` 加一筆，`appearances` 依經文順序列出 `{ place, r, note }`，需要時加 `name` 覆寫當時的稱呼。所屬時期由 `r` 的起點自動判斷。
- 新增對話：在 `encounters` 加一筆，`people` 是在場的人物，`lines` 的 `who` 可以是人物 id、`"narrator"`（旁白）或其他說話者的名字，`focus` 指定旁白時要動的人物，`ask` 是最後的反思問題。所屬時期由 `r` 自動判斷。

改了 js/css 之後，記得把版本號一起改：`index.html` 裡的 `?v=`，以及各個 js 檔 `import ... from "./xxx.js?v=N"` 的版本號（全部用同一個數字）。只改其中一處，瀏覽器可能拿到新舊混搭的檔案，畫面會整個停住。

## 說明

經文引用和合本（公共領域）。經緯度、年代與路線都是近似值，只用來排版，學界對部分地點與年代有不同看法。第三次旅程經過的「加拉太和弗呂家」以路司得、彼西底的安提阿代表。
